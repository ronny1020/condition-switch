# Contributing to condSwitch 🚀

First off, thank you for considering contributing to `condSwitch`! It's people like you that make the open-source community such a great place.

## Getting Started

1.  **Fork the repository:** Start by [forking the `condSwitch` repository](https://github.com/your-repo/fork) to your own GitHub account.

2.  **Clone your fork:**

    ```bash
    git clone https://github.com/your-username/condition-switch.git
    ```

3.  **Create a new branch:**

    ```bash
    git checkout -b your-branch-name
    ```

4.  **Set up the project:**

    ```bash
    pnpm install
    ```

## Development Process

- **Write clean code:** Make sure your code is easy to read and understand.
- **Add tests:** All new features and bug fixes should have corresponding tests.
- **Run tests:** Before submitting your changes, make sure all tests pass:

  ```bash
  pnpm test
  ```

- **Format your code:** This project uses Prettier for code formatting. Make sure your code is formatted before committing:

  ```bash
  pnpm prettier --write .
  ```

## Submitting a Pull Request

- **Push your changes:**

  ```bash
  git push origin your-branch-name
  ```

- **Open a pull request:** Go to the `condition-switch` repository and open a new pull request. Provide a clear description of your changes and link to any relevant issues.

## Code Style

This project uses [Prettier](https://prettier.io/) to maintain a consistent code style. Please make sure your code is formatted with Prettier before submitting a pull request.
